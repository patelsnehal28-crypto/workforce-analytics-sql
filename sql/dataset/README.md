# Dataset Information

## Overview

This folder contains the dataset used for the Workforce Analytics SQL Project. The dataset focuses on employee demographics, job-related attributes, job satisfaction, and attrition information.

## Dataset File

* **Analyzing Employee Trends.csv**

## Key Features

* Employee Number
* Gender
* Marital Status
* Age
* Age Band
* Department
* Education Level
* Education Field
* Job Role
* Business Travel
* Job Satisfaction
* Attrition Status
* Active Employee Status

## Purpose

The dataset is used to analyze:

* Employee attrition trends
* Department-wise workforce distribution
* Job satisfaction patterns
* Education and career relationships
* Business travel impact on employees
* Workforce demographics

## Data Source

This dataset is used for educational and analytical purposes as part of a SQL-based workforce analytics project.
